Select text, then click a style button to toggle it on/off. Nesting order when overlapping: Color → Italic → Obfuscated → Bold → Strikethrough → Underlined. Default color: #FFFFFF. Obfuscated text flickers like in Minecraft whenever the editor is not focused. Note: Line breaks are not supported in Minecraft item names/signs and are automatically removed.
